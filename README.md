# 🌍 Smart Travel Planner

An AI-powered travel planner built using Python and Streamlit.

## Features

- Weather Prediction
- Hotel Recommendation
- Budget Estimation
- AI Itinerary
- Packing Checklist
- Reflection Agent
- Download Travel Plan as PDF

## Technologies

- Python
- Streamlit
- JSON
- ReportLab

## Run

```bash
streamlit run app.py
```
